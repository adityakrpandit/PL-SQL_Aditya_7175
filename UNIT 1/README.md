# 📘 PL/SQL – Unit 1

This unit contains basic PL/SQL programs and practical exercises based on the BCA Semester 3 practical lab manual of Marwadi University.

## 📚 Course Information

- **Course:** Bachelor of Computer Applications (BCA)
- **Semester:** 3rd Semester
- **University:** Marwadi University
- **Subject:** PL/SQL
- **Unit:** Unit 1 – Basic PL/SQL Programs

## 🎯 Practicals Covered

1. Write a PL/SQL block to calculate Simple Interest.
2. Write a PL/SQL block to calculate the Square and Cube of a Number.
3. Write a PL/SQL block to calculate Product Discount.
4. Write a PL/SQL block to convert Feet into Centimeters, Inches, and Meters.
5. Write a PL/SQL block to convert Celsius into Fahrenheit.
6. Write PL/SQL blocks to generate numbers using `LOOP`, `FOR LOOP`, and `WHILE LOOP`.
7. Write a PL/SQL block to calculate the Total, Percentage, and Grade of a Student.
8. Write a PL/SQL block to calculate Employee Gross Salary.
9. Write a PL/SQL block to display Male Employees working in the HR Department.
10. Write a PL/SQL block to delete an Employee Record using EID.

## 🛠️ Concepts Used

- PL/SQL Block Structure
- Variables and Data Types
- User Input and Output
- Arithmetic Operations
- Conditional Statements
- `LOOP`, `FOR LOOP`, and `WHILE LOOP`
- Database Table Operations
- `SELECT` and `DELETE` Statements
- Employee and Student Data Processing

## 💻 Technologies Used

- SQL
- PL/SQL
- Oracle SQL*Plus

## ▶️ How to Execute

1. Open Oracle SQL*Plus.
2. Connect to your Oracle database.
3. Open the required `.sql` file or copy the program into SQL*Plus.
4. Execute the PL/SQL block.
5. Use `SET SERVEROUTPUT ON` to display output from `DBMS_OUTPUT.PUT_LINE`.
6. Check the output and verify the result.
