# 📘 PL/SQL – Unit 1

This unit contains basic PL/SQL programs and practical exercises based on the BCA Semester 3 practical lab manual of Marwadi University.

## 📝 Practicals Covered

1. Calculate Simple Interest
2. Calculate the Square and Cube of a Number
3. Calculate Product Discount
4. Convert Feet into Centimeters, Inches, and Meters
5. Convert Celsius to Fahrenheit
6. Generate Numbers Using `LOOP`, `FOR LOOP`, and `WHILE LOOP`
7. Calculate the Total, Percentage, and Grade of a Student
8. Calculate Employee Gross Salary
9. Display Male Employees Working in the HR Department
10. Delete an Employee Record Using EID

## 📚 Topics Covered

- PL/SQL Blocks
- Variables and Data Types
- User Input
- Arithmetic Operations
- Conditional Statements
- `LOOP`, `FOR LOOP`, and `WHILE LOOP`
- Database Tables
- `SELECT` and `DELETE` Operations
- Employee and Student Data Processing

## 🛠️ Technologies Used

- SQL
- PL/SQL
- Oracle SQL*Plus

## 🎯 Learning Objectives

- Understand the fundamentals of PL/SQL.
- Perform calculations using variables and operators.
- Implement different types of loops.
- Retrieve and delete records from database tables.
- Process student and employee information using PL/SQL.
